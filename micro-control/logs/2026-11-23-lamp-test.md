## ロービーム(純正LED、駆動ユニット 三菱 33109-T5A-J012 / W003T23781)

| 項目 | 結果 |
|---|---|
| 橙の線 | 点灯時 12V、消灯で 0V(ライトのスイッチに連動) |
| 黒の線 | GND |
| 赤の線 | 0V |
| 12V と GND だけをつなぐ | 点灯する(信号線は不要) |
| HW-039 から 1000Hz の PWM | 「ピーン」という音が出て、急に消えた。調光できなかった |
| 夕方の再テスト(200Hz、ガンマ1.0) | 反応なし。出力 100% を指示した状態でも点灯を確認できず、日没で中断 |

- 結論: 橙に 12V を入り切りする ON/OFF 制御はできる。PWM 調光は未確定。
- 1000Hz の失敗は、同日のテールと同じ一時的な不調だった可能性を否定できない(推測)。
- 夕方の無反応は原因未調査。次回は、出力 100% の状態で M+ と GND の間をテスターで測り、12V が出ているかを最初に確認する。
- `micro-control/CLAUDE.md` の「CH2 ロービーム = HID」は実車と合っていない(純正LED)。未修正。

## この日のソフトの変更

- `lamp-live`: PWM 周波数(50〜19000Hz)とガンマを画面から変更できる。設定値から計算した波形とガンマカーブを表示する。XY パッドを全画面にできる。
- `hibeam_live`: `f<Hz>` コマンドを追加。
- 画面の % と実際の出力の関係: 出力の割合 = (画面の割合)^ガンマ。ガンマ2.2 では画面 63% が出力 約36% になる。
