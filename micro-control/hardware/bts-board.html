MICRO-CONTROL / BTS6143D BOARD

BTS6143Dモジュールの基板配置

変換基板に付けたBTS6143D(下に5本のピン)を、ユニバーサル基板に立てて挿す配置です。回路は bts-wiring.html と同じで、基板は10×14穴(約25×36mm)を切り出せば足ります。

1. 部品の配置と裏面の配線

12V(Vbb)とOUTの太線は、ユーロブロックから変換基板のピンへまっすぐ縦に1本ずつ下ろします。ピン1とピン5はどちらもOUTなので、ピン5側を裏で上へ伸ばし、表面の被覆線で12Vの線をまたいでピン1側とつなぎます。信号の部品(Q1と抵抗5本)は変換基板の下と右にまとめ、ESPへの3本はXHポストから出します。

2. 穴ごとのつながり

線つなぐ点線の太さ
12Vユーロブロック12V → 変換基板ピン30.5sq
OUTユーロブロックOUT → ピン1。ピン5 → 表面の被覆線 → ピン1の線0.5sq
IN・CTRLピン2 → R_IN → Q1のC。Q1のB → R_B → XHのCTRL。Q1のB → R_BE → GND細線
ISピン4 → R_IS → GND。同じ点 → R_S → XHのIS細線
GNDユーロブロックGND、XHのGND、Q1のE、R_BE、R_IS を1本にまとめる細線
12Vの線の上を通るOUTの被覆線は、必ず被覆のある線を使ってください。裸線で渡すと、12VとOUTがショートし、BTSがONのままの状態と同じになって灯具が消せなくなります。抵抗の値は仮の値で、2SC1815の足の並び(E・C・B)も手持ちの部品の印字で確かめてください。
