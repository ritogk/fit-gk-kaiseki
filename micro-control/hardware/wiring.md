> 以下の本文は動作確認済みのCH1(フォグ×BTS7960)構成の記録。

```
[操作系] → ESP32-S3 → BTS7960 → フォグランプ
                ↑
        車載バッテリー → ヒューズブロック(ATO/ATC)
```

- 車両: ホンダ フィット GK系
- 灯火(CH1): ハロゲンフォグ。純正ヒューズ15A。バルブは H8 (35W=約2.9A/灯) の可能性が高い (刻印未確認)
- 電源: 車載12Vバッテリー → 5Aヒューズ(机上テスト時) → B+

## 設計原則

- **ヒューズは負荷ではなく「下流の最細電線」を守る**。容量は電線基準で決める
- **パワー線 (B+/B−/M+/M−) は 2.0sq・ネジ端子直結**。ブレッドボード禁止
- **GND はバスバー一点集約**。ただし灯具の − は M− へ戻す (バスバー直結すると PWM が効かない)
- 純正系統との共存は現状「純正スイッチOFF + 純正ヒューズ抜き」の暫定運用。恒久化は系統切替リレー (エーモン3237×2, NC=純正 / NO=自作のフェールセーフ) — ロードマップ参照

## 検証済みの事実

- M+/M− 電圧テスト合格: バッテリー12.6V時、体感30%指定→7V、体感100%(80%cap)→10V。ガンマ補正込みの計算値と一致
- 実フォグでの点灯・調光成功
- ソフトスタート (300ms) が実負荷で機能

## 実負荷テスト手順

1. 灯具を外し M+/M− にテスター → 体感30%→約7V / 100%→約10V (バッテリー12.6V時)
2. ソフトスタートの「ふわっと点灯」を目視確認
3. 30分点灯後に BTS7960 放熱板・端子を触診 (50℃以下であること)
