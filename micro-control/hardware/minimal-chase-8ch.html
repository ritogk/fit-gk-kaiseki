MICRO-CONTROL / MINIMAL 8CH CHASE

最小構成 8ch — 車の周りを光がぐるぐる回る初回実験

ハイビーム左右・ウィンカー4灯・バックランプ左右の8灯だけを、ESP32-S3 1台とハイサイドSW(BTS6143D)8個で制御する構成です。 17ch確定設計から切替リレー・CAN・2台目のESP・DCDC・監視タップを外し、灯具の純正カプラーを抜いて自作配線を差し替える仮設方式にしています。 純正に戻すときはカプラーを差し戻すだけです。停車中・パーキングでの実験専用です。

ぐるぐるの順番

上から見て時計回りに、左前ウィンカーから1灯ずつ点けていきます。1灯の点灯時間は200msなので、8灯で1周1.6秒になります。左の図は実際の速さで動いています。

ロービームは使いません。ロービームはHIDなので、点滅させるとバラストを傷め、消してから再点灯するまで数秒かかるためです。前方の「ヘッドライト」役はハイビームが担います。

ウィンカーやバックランプが電球(ハロゲン)の場合、点灯と消灯に数十msの遅れが出るため、光の尾を引くような見え方になります。LEDなら切れのよい動きになります。

結線図

電気の道は2本です。1本目は電力の道で、バッテリー → 20Aメインヒューズ → B+バス → chヒューズ → BTS6143D → 灯具 → ボディアースと流れます。2本目は指示の道で、Mac → USB → ESP32-S3 → 各BTSのINピンへ、点ける・消す・明るさの指示を送ります。ESPは電力を流さないので、USB給電だけで動きます。

実体配線図

上の結線図と同じ回路を、実物の見た目と置き場所に近い形で描いたものです。ヒューズの色は平型ヒューズの規格色(5A=タン、7.5A=茶、20A=黄)にそろえ、電線は太さに比例した線幅で描いています。

はんだ付けが要るのはBTS基板だけです。ヒューズボックス・バスバー・ブレッドボードは、ねじ止めと差し込みだけで組めます。BTSは差し替え式のカートリッジなので、壊れたときはソケットから抜いて交換できます。なお、ESPのピンの並び(ジャンパを挿す列)は説明用の配置なので、実物はボードの印字でGPIO10〜17を確かめてから挿してください。

17ch確定設計との違い

部品・機能17ch確定設計最小構成省ける理由
ESP32-S32台1台8chなら1台のピンで足りる
私設CAN(トランシーバ×2)ありなし前後のESP間通信が要らない
BTS6143D178制御する灯具が8灯
切替リレー(8chモジュール)17ch分なし純正線と同時につながないので、純正との切替が要らない
監視タップ(100k/22k+ツェナー)17組なし純正側が通電しない(カプラーを抜いている)ので見張る対象がない
DCDC 12V→5VありなしESPはMacのUSBから給電する
IN の10kΩプルダウン—8本(追加)USBを抜いた瞬間や起動中にINが浮いて誤点灯するのを防ぐ

やる順番

  1. 実車で8灯のバルブ規格と消費電流を確認します。特に、バックランプが左右2灯あるか、ハイビームがLEDかハロゲンかを確かめます。ハロゲンのハイビーム(60W級=約5A)だと7.5Aヒューズでは余裕が少ないため、ヒューズと電線を一段太くします。
  2. 各灯具の純正カプラーと同じ規格の「カプラー付き配線(メス側)」を8本用意します。純正線は切らず、差し替えだけで済ませるためです。
  3. 机上で1chだけ組みます。12V電源 → 5Aヒューズ → BTS6143D → テスト用電球で、ESPから点灯・消灯・調光ができることを確かめます。
  4. 8chに増やし、机上でぐるぐるの点灯パターンを確かめます。ESPの起動直後とUSBを抜いた直後に、全chが消えたままであることも確かめます。
  5. 実車では、エンジンを止めてキーを抜いてから8灯のカプラーを差し替えます。メイン20Aヒューズは最後に入れます。
  6. 終わったら、メイン20Aヒューズを抜いてから8灯のカプラーを純正に差し戻し、ウィンカー・ハザード・ハイビーム・バックランプが純正どおり点くかを確かめます。
この構成のまま走行しないでください。差し替え中の8灯は純正の操作では点かないため、ウィンカーとバックランプが働かなくなります。ブレーキランプとテールランプは触らないので純正のままです。
