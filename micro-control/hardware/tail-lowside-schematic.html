テール左右2灯をGND側で調光する回路図

テールの①には車の12Vを常時かけ、ランプの③(戻り)をD4184基板でバッテリー−へつないだり切ったりして明るさを変えます。ESP32はMacからUSBで給電し、基板の中のフォトカプラ越しに信号だけを送ります。車のカプラーは抜いて使う、停車中のテスト専用の回路です。

12V(ヒューズ後) ランプ戻り・バッテリー− ESPの信号(TRIG) ESPのGND(車とは別)

つなぎ方の一覧

どこからどこへ電線
バッテリー＋ヒューズ5A → 左右テールの①0.5sq以上(テールは1灯1A未満と推測)
左テールの③D4184基板 L の OUT−0.5sq以上
右テールの③D4184基板 R の OUT−0.5sq以上
基板L・基板R の VIN−バッテリー−0.5sq以上
ESP32 GPIO6 / GPIO4基板L / 基板R の TRIGジャンパー線
ESP32 GND基板L・基板R の TRIG側 GNDジャンパー線

基板のVIN＋・OUT＋は使いません。ランプの＋はヒューズから直接つなぎます。

動かし方と注意

ファームはhibeam_liveをそのまま使います。GPIO4が画面の1ch目(右)、GPIO6が2ch目(左)で、どちらもHIGHで基板が閉じて点灯します。起動時は両ピンLOWなので、ESPを差しても消灯のままです。

ESPのGNDとバッテリー−を分けてよいのは、D4184基板のTRIG側と出力側がフォトカプラで分かれているためです(推測)。組む前に、基板のTRIG側GNDとVIN−のあいだに導通がないことをテスターで確かめてください。

③がGNDであることは、まだ推測です。最初はlamp-liveで100%を出して点灯を確かめ、その後に調光を試します。フォトカプラは速い入り切りが苦手なので、1000Hzで低い%が効かない・ちらつく場合は、周波数を200〜500Hzへ下げて比べます(推測)。
