1灯ぶんの机上組み立て — ブレッドボードで良い所・ダメな所

区分の基準は流れる電流。信号(mA以下)=ブレッドボード可 / 電力(A級)=圧着・ネジ端子必須 / リレー・DCDC・変換基板は既製基板のまま使う。 部品は選定済みの実物(KOA 100kΩ/22kΩ・1N5226B・EALE 5A平型ヒューズ 等)を前提にした。

結線図と実装区分

バッジの意味 — BB可=ブレッドボードで組める(信号のみ) / 既製=既製モジュール・変換基板をそのまま使う / 端子=圧着・ネジ端子必須(ブレッドボード禁止)。部品クリックで詳細。

ブレッドボード実装(監視タップ + ESP)

⚠ 電力線(12V→灯具のA級電流)は絶対にブレッドボードへ載せない。接点の実力は1A程度で、3A流すと発熱・溶融する。

組立手順(この順で)

  1. 準備 — リレーモジュールの JD-VCC ジャンパを外す(ロジックとコイル電源の分離)。
  2. ブレッドボード — ESP32-S3 を挿し、監視タップを上図の列番号どおり組む。まず USB 給電だけで起動確認(12V系はまだつながない)。
  3. SENSE 単体テスト — タップ入力(col2)に12Vを付け外しして、ESPのログで HIGH/LOW が切り替わること。
  4. 信号線 — PWM→ハイサイドSW IN / SEL→リレーモジュール IN をジャンプワイヤで接続し、ESPのGNDとモジュールのGNDを共通化。
  5. 電力側(ブレッドボード禁止区間) — バッテリー+→20Aホルダー→5A平型→SW VS、SW OUT→リレーNO、COM→灯具+、灯具−→電源−。全て圧着・ネジ端子。
  6. 検証 — 灯具レスで COM 出力電圧(体感30%≈7V / 100%≈10V)→実負荷点灯→ソフトスタート目視→30分後に SW 端子を触診(50℃以下)。
  7. 恒久化 — 合格後、ブレッドボードの内容をユニバーサル基板へ移植(配置は board-layout-17ch.html)。
