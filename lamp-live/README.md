# lamp-live — ハイビーム左右のライブ操作画面

ブラウザの画面から WebSocket 経由でハイビーム左右を「演奏」するアプリ。
can-live / kline-app とは独立している(ポート 8200、コードの共有なし)。

```
ブラウザ ──WebSocket──▶ Mac のサーバ(FastAPI, 演出を40Hzで計算) ──USBシリアル──▶ ESP32(hibeam_live) ──▶ HW-039 ──▶ ハイビーム左右
```

## 起動

```bash
./lamp-live/run.sh        # http://localhost:8200/ が開く
./lamp-live/run.sh stop   # 止める(終了時に全消灯し、フェードを300msに戻す)
```

- ESP32 には `micro-control/firmware/hibeam_live` を書き込んでおく。
- シリアルポートは `/dev/cu.usbmodem*` を自動検出する。固定したいときは `HIBEAM_PORT=/dev/cu.xxx`。
- 依存はリポジトリ root の `.venv`(fastapi / uvicorn / pyserial)。

## 画面

| 操作 | 内容 | キー |
|---|---|---|
| パターン | 呼吸・左右交互・ウェーブ・高速ウェーブ・鼓動・ピンポン・ストロボ・ゆらぎ・きらめき・いきもの | 1〜0(同じキーで停止) |
| フラッシュ | 押している間だけ左右100% | Space |
| タップ | 拍に合わせて連打すると、パターンの1周期がその間隔になる | T |
| ブラックアウト | 出力だけを0にする(パターンは裏で進む) | B |
| 全停止 | パターン停止+手動0+消灯 | Esc |
| マスター / パターン量 / 速さ | 全体の明るさ / パターンの強さ / パターンの速さ(0.25〜8倍) | ↑↓ / — / ←→ |
| XYパッド・手動フェーダー | 横=左右の配分、縦=明るさ。離すと0に戻る | — |

出力は「ブラックアウト > フラッシュ > max(パターン×パターン量, 手動) × マスター」の順に決まる。

## 安全

- ESP32 側のフェードは演出中 40ms(LED想定)、終了時 300ms に戻す。ハロゲンをつなぐときは `LAMP_FADE_MS=300 ./lamp-live/run.sh` で起動する。
- ESP32 が再起動してフェードが300msに戻った場合は、サーバが検出して送り直す。
- 画面が切断されたときはフラッシュを解除する(点きっぱなし防止)。
